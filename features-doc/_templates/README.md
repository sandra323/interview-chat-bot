# Feature doc templates

Copy these into `features-doc/{feature-slug}/` (under `product/`, `engineering/`, `ui/`, `qa/` as appropriate).

Always add:

```yaml
feature: {feature-slug}
doc_role: current-state | design-intent | historical
last_verified: YYYY-MM-DD
```

Mark capabilities **shipped / partial / planned / deprecated / archived**.  
Create `engineering/current-state.md` as soon as anything ships.
